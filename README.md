# NUXYS-SPAM

NUXYS-SPAM adalah bot otomatis dengan keamanan tingkat tinggi.

## 🚀 Cara Menjalankan

1. Pastikan Anda telah menginstal Python 3 (disarankan versi 3.11+).
2. Instal semua modul yang dibutuhkan dengan menjalankan perintah berikut di terminal/CMD Anda:
   ```bash
   pip install -r requirements.txt
   ```
3. Jalankan bot dengan perintah:
   ```bash
   python main.py
   ```
4. Saat pertama kali dijalankan, Anda akan diminta memasukkan **Kode Lisensi**. Jika Anda belum memilikinya, silakan hubungi owner.
