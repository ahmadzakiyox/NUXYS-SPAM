## 🛠️ Instalasi & Cara Menjalankan

Ikuti langkah-langkah mudah di bawah ini untuk mulai menggunakan **NUXYS-SPAM**:

### 1. Download Repository
Lakukan clone repository ini atau download sebagai `.zip` lalu ekstrak.
```bash
git clone https://github.com/ahmadzakiyox/NUXYS-SPAM.git
cd NUXYS-SPAM
```

### 2. Install Modul yang Dibutuhkan
Instalasi secara otomatis menggunakan `pip`:
```bash
pip install -r requirements.txt
```

### 3. Jalankan Bot
Eksekusi file utama untuk masuk ke dalam *Command Center*:
```bash
python main.py
```
*(Tips: Gunakan aplikasi **Terminal** modern seperti Windows Terminal atau pastikan Terminal Anda mendukung UTF-8 agar tampilan lebih maksimal)*
